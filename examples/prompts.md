# Example Prompts

Use these prompts to test or apply the skill in Codex.

## Redesign an Existing Dashboard

```text
Use $apple-liquid-glass-ui to redesign this dashboard with Apple-inspired Liquid Glass UI. Keep dense data readable, use glass only for navigation and controls, and verify mobile and desktop layouts.
```

## Build a New App Shell

```text
Use $apple-liquid-glass-ui to build a responsive web app shell with a desktop sidebar, mobile bottom tabs, a glass command bar, accessible focus states, and dark mode support.
```

## Review a Pull Request

```text
Use $apple-liquid-glass-ui to review this UI change. Focus on hierarchy, glass overuse, contrast, responsive behavior, reduced motion, keyboard navigation, and whether the interface remains useful for the main workflow.
```

## Create CSS Tokens

```text
Use $apple-liquid-glass-ui to add reusable CSS tokens for an Apple-inspired glass material. Include light and dark mode, backdrop-filter fallback, reduced motion, high contrast, and forced-colors behavior.
```

## Improve a Modal or Sheet

```text
Use $apple-liquid-glass-ui to refine this modal into an Apple-inspired sheet. Keep destructive actions clear, form text readable, touch targets usable, and background transparency subtle.
```
