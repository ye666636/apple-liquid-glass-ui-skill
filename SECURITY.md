# Security Policy

## Supported Scope

This repository contains a Codex skill, reference notes, and implementation guidance. It should not require secrets, private customer data, proprietary assets, or production credentials.

## Reporting a Concern

Please open a GitHub issue if you find:

- Accidental exposure of sensitive information.
- Unsafe example code or scripts.
- Problematic dependency or supply-chain guidance.
- Licensing, attribution, or proprietary asset concerns.

If a report includes sensitive details, avoid posting secrets publicly. Open a minimal issue first and ask for a private follow-up channel.

## Maintainer Practices

- Keep examples free of real credentials and customer data.
- Avoid bundling proprietary Apple assets, SF Symbols, logos, or screenshots.
- Prefer progressive enhancement and accessibility-safe defaults.
- Review new scripts or templates before merging them into the skill.
